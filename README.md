Standalone Electron PDF reader built with TypeScript, React, PDF.js, and pdf-lib.

## Current Scope

- Open local PDFs.
- Open multiple PDFs as tabs.
- Drag and drop PDFs into new tabs.
- Light and dark themes.
- Page navigation, zoom, rotate, fit controls, single/two-page and scrolling modes.
- Add text, comments, highlights, and visual signatures.
- Fill detected PDF form fields from the form panel.
- Save, save as, export flattened PDF, and print.
